# Improvement notes

One file per generation of the improvement loop (`rsi improve`, `docs/RSI_LOOP.md`), written
by the generation itself before its change is checked: `gen-N.md` with the evidence it acted
on, the change, the scorecard number it predicts will move, and the result that would prove
it wrong. A note is on a branch `rsi/gen-N` until a person merges that branch.
